Instagram accounts

Connect your Business or Creator accounts through Composio. Studio only reads insights and never posts, and it never sees an Instagram password or token.

How does this work?
  1. Add your Composio API key to the server: npx wrangler secret put COMPOSIO_API_KEY on the deployed site, or COMPOSIO_API_KEY=… ./bridge/start.sh on your computer.
  2. Press Connect an Instagram account. Composio opens Instagram's own sign-in. Repeat to add more accounts.
  3. Come back and press Check again. Accounts you already connected in Composio show up automatically.

Set an APP_PASSCODE secret on the deployed site so only you can read the insights. To disconnect an account, remove it in the Composio dashboard.

How do these work, and what does it cost?

Sign in uses your own Claude Code on this computer, signed in to your Claude account, so usage comes from your Claude plan and no API key is needed. It needs the helper (./bridge/start.sh) and is meant for your own personal use on your own machine. For anything shared, hosted or commercial use an API key instead: Anthropic provides account sign-in for Claude Code itself, not for other apps.

API key: create one at console.anthropic.com and add a little credit. Each request costs a small fraction of a cent to a few cents. Set a spend limit on the key.

Edge voices are Microsoft's read-aloud voices. They are free but unofficial: Microsoft does not publish a public API for them, so they could change or stop working.

ElevenLabs: get a key in your ElevenLabs profile. Voice-overs use your plan's credits (about one credit per character).

Keys stay in this browser (this session only unless you tick Remember) and go straight to the service. Don't remember them on a shared computer.
