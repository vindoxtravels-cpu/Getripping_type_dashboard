Instagram accounts

Connect as many Business or Creator accounts as you manage. Studio reads their insights through Meta's official API. It only reads, never posts, and each token goes straight from this browser to Meta.

Add an account

How do I get a token?
  1. Open developers.facebook.com, create an app (type: Business) and add the Instagram product.
  2. Under API setup with Instagram login, add the Instagram professional account and click Generate token. Repeat for each account.
  3. Allow instagram_business_basic and instagram_business_manage_insights, then paste the token here.

Tokens expire (about 60 days for long-lived ones). Anyone with a token can read that account's insights, so don't save it on a shared computer.

AI & integrations

Add your Claude API key and Studio can do the heavy lifting for you.

  • Import a reel as a script. Paste a link or its caption and Claude writes a fresh hook and lines in your own words.
  • Direct the video. Claude picks an icon and highlighted words for every scene, plus the style, pace and effects.
  • Make one like your best reels. Claude studies a winner's structure and writes a new script on your topic.

Where do I get a key, and what does it cost?
  1. Sign in at console.anthropic.com and open API keys, then create a key.
  2. Add a little credit under Billing. Each script or direction costs a small fraction of a cent to a few cents depending on the model.

Your key is stored only in this browser and requests go straight to Anthropic, never through anyone else. Set a monthly spend limit on the key in the console, and don't remember it on a shared computer. Anyone using this browser profile could use it.
